# Лабораторная работа по линейному программированию

## Как работать над проектом

1. Склонируйте репозиторий.
2. Создайте новую ветку и назовите её своим именем, но так чтобы было прикольно.
3. Сделайте свой кусочек.
4. Закомитьте что нашкодили.
5. На GitHub создайте **Pull Request (PR)** из своей ветки в основную. После проверки попросите лидора выполнить merge, если не хотите делать это самостоятельно.

Если страшно самому принимать мерж попросите лидора.

## Что уже готово

- Консольное меню с выбором задачи и повторным показом после выполнения.
- Ввод условий линейной и транспортной задач; можно повторно использовать последнее введённое условие в рамках текущего запуска.
- Транспортная задача: закрытие баланса, построение начального плана методом северо-западного угла, его улучшение методом потенциалов до оптимального и расчёт минимальной стоимости.
- Проверка формы и размеров входных данных линейной задачи в `linear_programming/problem.py`.
- Вывод матриц и целевых функций в `linear_programming/display_methods/`.
- Структура для алгоритмов в `linear_programming/math_tasks/`.
- `.gitignore` для файлов Python и популярных редакторов.

## Что нужно реализовать

Большинство алгоритмических функций пока являются заглушками: они показывают введённое условие и возвращают текстовое сообщение вместо решения. Реализуйте методы по алгоритму, который изучаете на занятиях:

- `math_tasks/simplex.py` — симплекс-метод;
- `math_tasks/dual_simplex.py` — двойственный симплекс-метод;
- `math_tasks/artificial_basis.py` — метод искусственного базиса;
- `math_tasks/primal_dual.py` — совместное решение прямой и двойственной задач;
- `math_tasks/optimality.py` — проверка решения на оптимальность;
- `math_tasks/canonical_form.py` — приведение к канонической форме;
- `math_tasks/standard_form.py` — приведение к стандартной форме.

Для четырёх методов решения линейной задачи интерфейс принимает матрицу коэффициентов `A`, правые части `b`, коэффициенты целевой функции `c` и направление `sense` (`"max"` или `"min"`). После реализации эти методы должны возвращать вектор решения. Преобразования форм и проверка оптимальности также оставлены для самостоятельной реализации.

Для транспортной задачи используется последовательность из методички: метод северо-западного угла строит начальный план, затем метод потенциалов проверяет оптимальность и перераспределяет поставки по циклам до получения оптимального плана.

## Ввод задачи

Чтобы запустить приложение, установите зависимости проекта из `requirements.txt`.

Матрицы вводятся по строкам: элементы одной строки разделяются запятыми, строки — точкой с запятой. Например, матрица
`[[1, 2], [3, 4]]` вводится так:

```text
1, 2; 3, 4
```

Векторы вводятся через запятую, например `4, 5`. Для линейной задачи после матрицы `A` введите вектор правых частей `b`, коэффициенты функции `c` и направление `max` или `min`.

## Веб-интерфейс

Запустите локальный HTTP-сервер:

```bash
python main.py
```

Откройте `http://localhost:8000`. Сервер привязан только к `127.0.0.1`; другой порт можно указать параметром, например `python main.py --port 8080`. Веб-интерфейс предоставляет список задач через `GET /api/tasks` и принимает условия для решения через `POST /api/solve`. Заполненные условия хранятся в `localStorage` браузера. Прежнее консольное меню доступно командой `python main.py --cli`.
