# Лабораторная работа по линейному программированию

## Запуск

```bash
./run.sh
```

При первом запуске `run.sh` создаёт виртуальное окружение и устанавливает зависимости из `requirements.txt`. Затем появится числовое меню; выберите задачу, введя её номер. Условие задачи вводится после выбора: строки матрицы `A`/тарифов разделяются точкой с запятой, числа в строке — запятыми (пример: `1, 2; 3, 4`). Последнее условие сохраняется в памяти программы отдельно для линейных и транспортных задач; при следующем выборе совместимой задачи можно нажать Enter, чтобы использовать его, или `n`, чтобы ввести новое. Результат выводится зелёным цветом. Выйти можно пунктом `0`.

## Структура

- `problem.py` — создание и проверка задачи `A*x = b`, целевая функция `c*x` и направление `max`/`min`.
- `math_tasks/` — алгоритмы решения (`simplex.py`, `dual_simplex.py`, `artificial_basis.py`, `transport.py`, `primal_dual.py`, `optimality.py`) и отдельные модули преобразования к канонической и стандартной формам.
- `display_methods/` — методы вывода матриц и целевых функций.

Четыре метода решения СЛАУ с целевой функцией принимают `A`, `b`, коэффициенты `c` и направление `sense` (`"max"` или `"min"`); при реализации они должны возвращать вектор решения (`numpy.matrix`). Сейчас все ещё не реализованные методы явно выводят условие заглушки и возвращают текстовый ответ-заглушку. Матрицы задачи хранятся как `numpy.matrix`, а для точного отображения используются объекты SymPy.
